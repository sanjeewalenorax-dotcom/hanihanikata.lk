# හනිහනිකට.lk — Full Stack V1
Brand: sanjeewalenora

## Included
- Responsive marketplace frontend
- Sinhala / English / Tamil language UI shell
- AI Search UI and voice-search hook
- Categories, featured/latest/popular/nearby listings
- Post Ad flow shell
- User / Agent / Admin dashboard shells
- Role-based access model
- Payment, verification, reports, notifications and audit-log data models
- Backend API starter with Express
- SQLite database starter

## Run
1. Install Node.js 20+
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:3000`

This is a runnable V1 foundation. Production integrations (Google/Facebook OAuth, SMS provider, payment gateway, WhatsApp API, real AI model, cloud storage, production database and deployment secrets) must be configured with provider credentials.
